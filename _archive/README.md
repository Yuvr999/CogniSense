# 🗄️ CogniSense Archive

This directory contains preserved legacy prototypes, initial scaffolding scripts, and scratch files used during early research and development. 

### Archived Files:
* `alzheimers_ml_pipeline.py`: Initial monolithic prototype script before modularization into `src/cognisense/`.
* `scaffold.py`: Initial repository structure bootstrapping script.
* `write_files.py`: One-off scratch utility.

> **Note**: Active production code is maintained in `src/cognisense/` (core library), `backend/` (FastAPI service), `frontend/streamlit/` (clinician dashboard), and `frontend/react/` (patient portal).
